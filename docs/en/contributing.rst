기여 가이드 (Contributing)
===========================

버그 제보 및 기능 제안
----------------------

* 버그나 개선 아이디어가 있다면 GitHub 저장소의 `Issues <https://github.com/roboticsware/pgzhelper/issues>`_\ 에 등록해 주세요.

개발 참여 방법
--------------

1. 저장소를 Fork합니다.
2. 기능 브랜치를 생성합니다: ``git checkout -b feature/awesome-feature``
3. 변경 사항을 커밋합니다: ``git commit -m "feat: add awesome feature"``
4. 브랜치에 푸시합니다: ``git push origin feature/awesome-feature``
5. Pull Request를 생성합니다.
