Loyiha hissasini qo'shish
=========================

Xatolar va takliflar
--------------------

* Xatolar yoki yaxshilash takliflari bo'lsa, `GitHub Issues <https://github.com/roboticsware/pgzhelper/issues>`_ sahifasida qoldiring.

Rivojlantirish jarayoni
-----------------------

1. Omborni Fork qiling.
2. Yangi tarmoq oching: ``git checkout -b feature/awesome-feature``
3. O'zgarishlarni kiritib commit qiling: ``git commit -m "feat: add awesome feature"``
4. Tarmoqqa yuklang: ``git push origin feature/awesome-feature``
5. Pull Request yuboring.
